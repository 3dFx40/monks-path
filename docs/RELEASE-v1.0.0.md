# דרך הנזיר 1.0.0

משחק פעולה בעברית לנייד ולמחשב: נזיר מול אורקים, חמישה עולמות, 15 זירות ו־15 בוסים, נשקים, קסמים וקומבואים.

- [לשחק בדפדפן](https://3dfx40.github.io/monks-path/)
- [הסברים וצילומי מסך לשיתוף](https://3dfx40.github.io/monks-path/share.html)
- [הוראות התקנה ובנייה](https://github.com/3dFx40/monks-path/blob/main/docs/ANDROID.md)

## התקנה בנייד

הורידו את `monks-path-1.0.0.apk` המצורף ופתחו אותו בנייד. אם נדרש, אפשרו התקנה ממקור זה. נדרש Android 8.0 ומעלה ו־Android System WebView מעודכן. המשחק עובד ללא אינטרנט, במסך אופקי, עם שליטת מגע ושמירה מקומית.

## קבצי ההפצה

- `monks-path-1.0.0.apk`: חבילת Android עם חתימת הפצה RSA, מאומתת ב־APK Signature Scheme v2 ו־v3.
- `SHA256SUMS.txt`: סכום SHA-256 של ה־APK לבדיקת שלמות ההורדה.
- `signing-certificate.pem`: התעודה הציבורית לזיהוי חתימת ההפצה.

טביעת SHA-256 של תעודת החתימה:

```text
d19597db0fafbf38456838061e25b09eb70b2f2d4bf15c489339addb631fd813
```

השמירה נפרדת בין הדפדפן לאפליקציה. אין גרסת iOS כרגע.
