# דרך הנזיר 1.0.4

כלל הפסילות תוקן:

- מתחילים עם שלוש פסילות לכל המסע, בכל רמת קושי.
- הפסילה הראשונה מחזירה לתחילת העולם הנוכחי עם שתי פסילות שנותרו.
- הפסילה השנייה מחזירה לתחילת העולם הנוכחי עם פסילה אחת שנותרה.
- הפסילה השלישית היא Game Over. המסע השמור מסתיים, ואפשר להתחיל מסע חדש.
- מעבר לעולם הבא, חזרה מנקודת שמירה ופתיחה מחדש של המשחק אינם מחדשים פסילות.

החיים המלאים נשארים 120 בתחילת המסע. בחזרה לתחילת עולם נשמרים הציוד, הדרגה והניקוד שהיו בנקודת הכניסה אליו. מספר הפסילות שנותרו מוצג במסך החזרה.

[משחק WEB](https://3dfx40.github.io/monks-path/) · [הוראות ותמונות](https://3dfx40.github.io/monks-path/share.html)
