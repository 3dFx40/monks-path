# דרך הנזיר 1.0.3

- החיים ההתחלתיים של הגיבור עלו מ־100 ל־120. גם שמירות קיימות מקבלות תוספת חד־פעמית של 20 לחיים הנוכחיים ולמקסימום החיים.
- כל עולם כולל שלוש זירות. השלמתן שומרת אוטומטית את נקודת הכניסה לעולם הבא.
- כשנגמרות כל הפסילות, חוזרים לתחילת העולם הנוכחי עם חיים מלאים ופסילות מחודשות. הציוד, הדרגה, הזהב והניקוד חוזרים לערכים שהיו בכניסה לעולם.
- נקודת החזרה נשמרת גם אם סוגרים את המשחק לאחר פסילה. השמירה הרגילה באמצע הקרב ממשיכה לפעול.
- לשמירות ישנות ללא נקודת עולם נוצרת נקודת חזרה בתחילת העולם הנוכחי, עם הציוד הקיים.
