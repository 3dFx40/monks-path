# דרך הנזיר 1.0.1

גרסת WEB ו־Android מעודכנת עם כל שינויי הלחימה והאמנות האחרונים.

- נשקים נפרדים מהדמויות עם אנימציות בהתאם לציוד: חנית, פטיש, שרשרת, מוט גחלת וקשת לאויבים.
- נזק, טווח ומהירות ההתקפה והקומבואים תלויים בנשק המצויד.
- אורקים ובוסים חזקים יותר, עם טווחי תקיפה ונשקים שמתאימים לסוג שלהם.
- עדכון חד־פעמי של שמירות קרב ישנות, תוך שמירה על אחוז החיים שנותר לאויבים.
- צילומי מסך עדכניים והוראות בעברית.

[לשחק ב־WEB](https://3dfx40.github.io/monks-path/) · [הוראות ותמונות לשיתוף](https://3dfx40.github.io/monks-path/share.html)

## עדכון Android

הורידו את `monks-path-1.0.1.apk` המצורף והתקינו מעל הגרסה הקיימת. אין צורך להסיר את האפליקציה. החבילה משתמשת באותו מזהה אפליקציה ובאותו מפתח חתימה כמו 1.0.0, וקוד הגרסה עלה מ־1 ל־2.

נדרש Android 8.0 ומעלה. המשחק עובד ללא אינטרנט. השמירה מקומית ואינה מסתנכרנת בין האפליקציה לדפדפן.

מצורפים גם `SHA256SUMS.txt` לבדיקת שלמות ההורדה ו־`signing-certificate.pem`, התעודה הציבורית. מפתח החתימה והסיסמה נשארים מחוץ למאגר.

## בדיקות

מסע אוטומטי השלים את כל 15 הזירות והבוסים. בדיקות נשקים, קסמים, מגנים, שמירות ושליטת מגע עברו ללא שגיאות דפדפן. בדיקה במכשיר Samsung Galaxy A73 עם Android 16 אימתה טעינת אמנות, תנועה והתקפה במגע ושמירה והמשך לאחר טעינה מחדש. כל 19 קובצי המשחק והאמנות שב־APK נבדקו מול קובצי המקור; חתימת ההפצה אומתה.
## כפתורים נוחים יותר בנייד

כפתורי התנועה והפעולות גדלו ל־48–56 פיקסלים, עם מרווחים ביניהם. גם כפתורי הציוד, ההשהיה, התפריטים וההגדרות הוגדלו. הפריסה מותאמת למסך לאורך ולרוחב, ובמסכים צרים במיוחד כפתורי הפעולה מסודרים בשתי עמודות.
