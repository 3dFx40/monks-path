# גרסת Android

ה־APK מכיל את המשחק והאמנות ועובד ללא אינטרנט. הוא נפתח במסך אופקי, תומך במגע ובשמירה מקומית ומשהה את הקרב כשעוברים לאפליקציה אחרת. כפתור החזרה משהה קרב; לחיצה נוספת מציגה אפשרות יציאה.

דרישות: Android 8.0 ומעלה ו־Android System WebView מעודכן. השמירה באפליקציה נפרדת מהשמירה בדפדפן. הסרת האפליקציה מוחקת את השמירה שלה.

## התקנה

1. הורידו את `monks-path-1.0.4.apk` מעמוד [ההפצות](https://github.com/3dFx40/monks-path/releases/latest).
2. פתחו את הקובץ בנייד. אם Android מבקש, אפשרו התקנה מהדפדפן או ממנהל הקבצים שבו פתחתם אותו.
3. התקינו ופתחו את **דרך הנזיר**. בעדכון עתידי התקינו מעל הגרסה הקיימת כדי לשמור על ההתקדמות.

## בנייה וחתימה ב־Windows

נדרשים JDK 17 ומעלה, Android SDK Platform 35 ו־Build Tools 35.0.0. הגדירו `JAVA_HOME` ו־`ANDROID_HOME`, ואז הריצו משורש הפרויקט:

```powershell
pwsh -NoProfile -File scripts/build-android.ps1
# גרסה חדשה: יש להגדיל את קוד הגרסה
pwsh -NoProfile -File scripts/build-android.ps1 -VersionName 1.0.5 -VersionCode 6
# לצורכי פיתוח בלבד: מאפשר בדיקת WebView בכלי דפדפן
pwsh -NoProfile -File scripts/build-android.ps1 -DebugBuild
```

התוצרים נמצאים ב־`dist`: APK חתום, תעודת חתימה ציבורית ו־`SHA256SUMS.txt`. הבנייה משתמשת ישירות בכלי Android הרשמיים, ללא Gradle וללא ספריות צד שלישי. מקור ה־Java נמצא ב־`android/src`; קובצי המשחק נכללים בחבילה מאותה רשימת קבצים שמשמשת לפרסום WEB.

בדיקת התאמת קובצי המשחק והתמונות למקור: `python scripts/verify-apk.py`. חבילת פיתוח מקבלת סיומת `-debug` ואינה מיועדת להפצה. חבילת ההפצה אינה מאפשרת איתור באגים ב־WebView.

בבנייה הראשונה נוצר מפתח הפצה RSA עם 3,072 ביט בתיקיית `.signing`. זו חתימת הפצה עצמית, לא מפתח debug. התיקייה כוללת מפתח וסיסמה ומוחרגת מ־Git. **גבו את כל התיקייה במקום פרטי**: עדכונים לאותה אפליקציה חייבים להיחתם באותו מפתח. אובדן המפתח מונע התקנת עדכון מעל האפליקציה הקיימת. אין להעלות מפתח או סיסמה לגיטהאב.

טביעת SHA-256 של תעודת החתימה לגרסה הראשונה:

```text
d19597db0fafbf38456838061e25b09eb70b2f2d4bf15c489339addb631fd813
```

חתימת APK מאומתת עם `apksigner verify --verbose --print-certs`. פרטי האריזה והחתימה מבוססים על [כלי הבנייה של Android](https://developer.android.com/build/building-cmdline) ו־[תיעוד apksigner](https://developer.android.com/tools/apksigner).

החבילה אינה מבקשת הרשאות רשת, אחסון, מצלמה או מיקום. היא טוענת תוכן מקומי ב־WebView דרך מקור HTTPS קבוע, חוסמת קבצים וכתובות חיצוניות, ואינה חושפת גשר JavaScript לקוד Android. התעודה הציבורית מותרת לשיתוף; המפתח הפרטי נשאר אצל בעל הפרויקט.
